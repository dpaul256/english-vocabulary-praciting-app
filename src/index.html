規則

  1. 答錯或跳過會加入錯題簿。
  2. 每個單字會記錄答對率與連對次數。
  3. 同一單字連續答對 3 次會標記「已學會」，一般題庫不再出現。
  4. 錯題簿不會重複收同一個單字。
  5. 錯題重測需手動點選，會依 10 / 20 / 30 設定從錯題簿隨機抽題。
  6. 錯題重測考完後，只會從錯題簿移除本次抽到的那批單字。
  7. 手打答案只會和原始答案比對，不使用 API 或 Qwen 語意判斷。
